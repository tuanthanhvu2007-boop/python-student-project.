# Project Python: Quản lý điểm sinh viên

## Chạy trên máy tính
1. Cài Python.
2. Mở terminal tại thư mục chứa `app.py`.
3. Cài thư viện: `pip install -r requirements.txt`
4. Chạy ứng dụng: `streamlit run app.py`

## Đưa lên Streamlit Community Cloud để có link công khai
1. Đăng nhập GitHub và tạo repository mới.
2. Tải `app.py` và `requirements.txt` lên repository.
3. Mở https://share.streamlit.io/ hoặc https://streamlit.io/cloud và đăng nhập.
4. Chọn **Create app**, chọn repository, branch `main`, file chính `app.py`.
5. Nhấn **Deploy**. Sau khi triển khai thành công, Streamlit sẽ cấp link dạng `https://ten-app.streamlit.app`.

Dữ liệu hiện tại là dữ liệu mẫu. Hãy thay họ tên, MSSV và điểm theo yêu cầu của lớp trước khi nộp.
